# Contributing

Спасибо за интерес к проекту!

## Как начать
1. Fork и клон репозитория
2. `pip install -r requirements.txt`
3. Скопируй `.env.example` → `.env` и заполни ключи
4. Прогони тесты: `pytest -q`

## Правила кода
- Type hints на публичных функциях
- Секреты — только через переменные окружения, никогда в коде
- Коммиты в формате conventional commits: `feat:`, `fix:`, `docs:`

## Идеи и баги
Открывай Issue — посмотрю и отвечу.
